StudyPilot - Spring Boot Backend (Running)

The Spring Boot server is running on port 8080.

Open Frontend App (localhost:3000) | Open H2 Database Console

Active REST Endpoints:

  • POST /api/auth/register - Register user
  • POST /api/auth/login - Login user
  • GET /api/syllabi - Get all subjects
  • POST /api/syllabi/text - Add subject from text/paragraph
  • POST /api/syllabi/pdf - Add subject from PDF (Apache PDFBox)
  • DELETE /api/syllabi/{id} - Delete subject
  • POST /api/plans/generate - Generate daily study plan
  • GET /api/sessions - Get study sessions
  • POST /api/sessions/{id}/complete - Mark session complete
