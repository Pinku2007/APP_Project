# StudyPilot

StudyPilot is a simple study planner web application made for our college project. It helps students manage their exams by letting them add subjects by typing or uploading a syllabus PDF, set their exam dates and daily study hours, and automatically creates a day-by-day study timetable. It also shows YouTube video tutorials and notes for each topic to help study. The project frontend is made using Next.js and Bootstrap, and the backend is made using Spring Boot, Apache PDFBox, and H2 database.
